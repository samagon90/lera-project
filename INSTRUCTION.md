# Инструкция по работе с сайтом питомника «ДарЛес»

Этот документ написан для человека **без знания кода**. Здесь всё, что нужно,
чтобы добавлять растения, менять фото и восстановить сайт с нуля.

---

## 1. Как устроены файлы сайта

```
lera-project/
├── index.html          — Главная страница
├── catalog.html        — Каталог (3 вкладки: Хвойные / Лиственные / Многолетние)
├── product.html        — Страница одного растения (открывается кликом по карточке)
├── css/
│   └── style.css       — Все цвета, шрифты, отступы (дизайн сайта)
├── js/
│   ├── products.js     — ★ ВАШ ФАЙЛ: список всех растений каталога
│   └── site.js         — Шапка, подвал, контакты, карусели (техническое)
├── images/
│   ├── logo/           — логотипы (цветной и белый)
│   ├── nursery/        — фото питомника (Hero и карусель)
│   └── catalog/        — ★ фото растений и иконки категорий
└── INSTRUCTION.md      — этот файл
```

**Вам почти всегда нужны только два места:**
- файл `js/products.js` — тексты, названия, цены;
- папка `images/catalog/` — фотографии растений.

---

## 2. Как добавить новое растение в каталог (пошагово)

> ✨ **Проще всего — через админ-панель:** откройте `admin.html` на сайте
> (ссылка «Админ-панель» внизу каждой страницы). Фото перетаскивается мышкой,
> текст — копируется и вставляется, кнопка «Опубликовать» сама обновляет сайт.
> Подробнее — в ШПАРГАЛКА.md, Задача 2. Способ ниже — запасной, вручную.


### Шаг 1. Положите фотографию
Скопируйте фото растения в папку `images/catalog/`.

Правила для имени файла:
- только латинские буквы, цифры и дефис: `tuya-brabant.jpg` (НЕ «Туя Брабант.jpg»);
- расширение `.jpg` или `.png`;
- размер фото — примерно 1200×900 пикселей, вес желательно до 500 КБ.

### Шаг 2. Откройте файл `js/products.js`
Открыть можно «Блокнотом», VS Code или прямо на GitHub (кнопка с карандашом ✏️).

### Шаг 3. Скопируйте шаблон и вставьте его в конец списка
Найдите в конце файла последний товар — он заканчивается так:

```js
  }
];
```

Поставьте **запятую** после закрывающей `}` последнего товара и вставьте новый блок:

```js
  {
    id: 10,
    name: "Туя западная «Брабант»",
    category: "hvoynye",
    price: 1300,
    image: "images/catalog/tuya-brabant.jpg",
    gallery: [],
    short: "Быстрорастущая туя для высокой изгороди",
    description: `Первый абзац описания.

Второй абзац: высота взрослого растения, зона морозостойкости, почва и освещение.

Третий абзац: уход, скорость роста, применение в ландшафтном дизайне.`
  }
];
```

### Шаг 4. Сохраните файл и обновите страницу
Растение сразу появится в каталоге, в карусели на главной и получит собственную страницу.

---

### Что означает каждое поле

| Поле | Что писать | Пример |
|---|---|---|
| `id` | Уникальный номер. Просто прибавьте 1 к последнему. | `10` |
| `name` | Название растения в кавычках `"..."` | `"Ель колючая «Глаука»"` |
| `category` | Ровно одно из трёх слов: `hvoynye`, `listvennye`, `mnogoletnie` | `"hvoynye"` |
| `price` | Цена **числом**, без пробелов и без знака ₽ | `1500` |
| `image` | Путь к фото | `"images/catalog/el-glauka.jpg"` |
| `gallery` | Доп. фото. Если их нет — оставьте `[]` | `["images/catalog/el-2.jpg"]` |
| `short` | Одна короткая строка под названием в карточке | `"Голубая ель для акцента"` |
| `description` | Длинный текст. Между абзацами — **пустая строка** | см. шаблон выше |

**Важные мелочи, чтобы ничего не сломалось:**
- Текст описания пишется между «косыми кавычками» \`…\` (символ на клавише «ё», раскладка англ.).
- Между товарами обязательно стоит запятая, после последнего товара запятой НЕТ.
- Внутри `name` и `short` используйте «ёлочки» «...», а не прямые кавычки `"`.

## 3. Как изменить или удалить растение

- **Изменить**: найдите нужный блок в `js/products.js`, поправьте текст/цену, сохраните.
- **Удалить**: удалите блок целиком — от `{` до `}` — и лишнюю запятую.

## 4. Как заменить фотографии сайта

| Что заменить | Файл в репозитории |
|---|---|
| Файл №1 — фон первого экрана (Hero) | `images/site/1.jpg` |
| Файл №2, №3, №4 — карусель фото питомника | `images/site/2.jpg`, `3.jpg`, `4.jpg` |
| Файл №5 — белый логотип на Hero (PNG, прозрачный фон) | `images/site/5.png` |
| Файл №6 — цветной логотип в верхней полоске | `images/site/6.jpg` |
| Файл №7 — круглая иконка «Хвойные» | `images/site/7.jpg` |
| Файл №8 — круглая иконка «Лиственные» | `images/site/8.jpg` |
| Файл №9 — круглая иконка «Многолетние» | `images/site/9.jpg` |
| Файлы №10–№22 — фото растений каталога | `images/catalog/10.jpg` … `images/catalog/22.jpg` |
| Фото в блоке «О нас» | `images/site/2.jpg` |

Нумерация файлов полностью совпадает с вашим техническим заданием:
достаточно переименовать «файл 14.jpg» в `14.jpg` и положить в `images/catalog/`.

Просто перезапишите файл с тем же именем — на сайте картинка обновится
(иногда нужно нажать Ctrl+F5, чтобы браузер сбросил кэш).

## 6. Как запустить сайт у себя на компьютере

### Вариант А — самый простой
Скачайте папку с сайтом и **дважды кликните `index.html`**. Он откроется в браузере
и будет полностью работать (каталог, вкладки, страницы товаров).

### Вариант Б — локальный сервер (ближе к «боевому» режиму)
Нужен установленный Python 3.

```bash
cd путь/к/папке/lera-project
python3 -m http.server 3000
```
Затем откройте в браузере `http://localhost:3000`.

### Вариант В — восстановление из GitHub
```bash
git clone https://github.com/samagon90/lera-project.git
cd lera-project
python3 -m http.server 3000
```

## 7. Как опубликовать сайт в интернете бесплатно (GitHub Pages)

1. Откройте репозиторий на GitHub → вкладка **Settings**.
2. Слева выберите **Pages**.
3. В разделе *Build and deployment* → Source: **Deploy from a branch**.
4. Branch: выберите нужную ветку и папку `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://samagon90.github.io/lera-project/`.

## 8. Как сохранить изменения в GitHub

Самый простой путь — через сайт GitHub:
1. Откройте файл `js/products.js` в репозитории.
2. Нажмите карандаш ✏️ (Edit).
3. Внесите правки → внизу кнопка **Commit changes**.
4. Фото загружаются так: зайдите в папку `images/catalog` → **Add file → Upload files**.

Через программу (если работаете локально):
```bash
git add .
git commit -m "Добавила новое растение"
git push
```
