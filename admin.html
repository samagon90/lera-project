Публикация на сайт

Чтобы растения появлялись на сайте «в один клик», подключите панель к репозиторию GitHub.

Как получить токен: github.com → Settings → Developer settings → Fine-grained tokens → Generate new token → в «Repository access» выберите только lera-project, в Permissions → Contents → Read and write. Токен хранится только в вашем браузере и никому не передаётся, кроме GitHub. Открыть страницу токенов →

Без токена панель работает в «локальном режиме»: кнопка «Скачать файлы» выдаст готовые файлы — их нужно загрузить в репозиторий вручную (кнопка Add file → Upload files).
