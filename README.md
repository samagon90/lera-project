# Питомник декоративных растений «ДарЛес» — сайт-витрина

Статический сайт-витрина (без корзины и оплаты) для питомника «ДарЛес», Крым,
с. Давыдово, трасса Донское — Кленовка.

**Стек:** чистые HTML + CSS + JavaScript. Без сборки, без npm, без сервера —
достаточно открыть `index.html` в браузере.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: шапка с контактами, Hero с логотипом, блок «Что такое ДарЛес?», карусель фото питомника, кнопка «Каталог» + карусель товаров, круглые кнопки категорий, тёмный подвал с соцсетями |
| `catalog.html` | Каталог с вкладками «Хвойные / Лиственные / Многолетние», поиском и сортировкой по цене |
| `product.html` | Страница растения: галерея, название, цена, развёрнутое описание, кнопки «Связаться» |

## Где что лежит

```
css/style.css      — дизайн (белый фон, тёмно-зелёный/серый/чёрный, шрифт Inter)
js/products.js     — ★ каталог растений: сюда добавляются товары
js/site.js         — контакты, шапка, подвал, карусели
images/site/       — 1.jpg Hero, 2–4.jpg карусель питомника, 5.png белый логотип,
                     6.jpg цветной логотип, 7–9.jpg круглые иконки категорий
images/catalog/    — 10.jpg … 22.jpg — фотографии растений каталога
```

## Добавить растение за 4 шага

1. Положите фото в `images/catalog/` (латинское имя файла, напр. `tuya-brabant.jpg`).
2. Откройте `js/products.js`.
3. Скопируйте последний блок `{ ... }`, вставьте после него через запятую, поменяйте
   `id`, `name`, `category` (`hvoynye` / `listvennye` / `mnogoletnie`), `price`, `image`, `short`, `description`.
4. Сохраните и обновите страницу — растение уже в каталоге.

Подробная пошаговая инструкция со скриншотными пояснениями и разбором всех полей —
в файле **[INSTRUCTION.md](INSTRUCTION.md)**.
